refactor(monitoring): 코드 스타일 가이드 준수를 위한 메트릭 저장소 리팩토링

- MetricsStorageFactory: 내부 클래스 JavaDoc 추가 (@author, @version, @since)
- MetricsStorageFactoryImpl: 
  - 클래스 레벨 @Transactional(readOnly = true) 추가
  - 로깅 패턴을 [MetricsStorageFactoryImpl] methodName - ... 형식으로 변경
  - 메서드 JavaDoc에 @param, @return, @throws 태그 추가
  - private 메서드 JavaDoc 태그 추가
- InfluxDBStorage, PrometheusStorage, TimescaleDBStorage:
  - 로깅 패턴을 [ClassName] methodName - ... 형식으로 통일
- 테스트 파일 리팩토링:
  - 테스트 메서드 네이밍 규칙 적용 (methodName_WhenCondition_ExpectedResult)
  - Given-When-Then 패턴 대문자 주석으로 통일
  - @Nested 클래스로 테스트 그룹화
  - 클래스 JavaDoc @since 날짜를 2025-11-13으로 통일
